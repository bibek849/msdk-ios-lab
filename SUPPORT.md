# Questions and support

- Use [Discussions](https://github.com/bibek849/msdk-ios-lab/discussions) for onboarding, research questions and design proposals.
- Use [issues](https://github.com/bibek849/msdk-ios-lab/issues) for reproducible defects and agreed tasks. Include a small synthetic example and the exact revision/environment.
- Use a PR for code or documentation. Follow the [AI contributor workflow](docs/AI_CONTRIBUTOR_WORKFLOW.md) if working with an agent.
- Request local hardware testing through the [hardware request template](.github/ISSUE_TEMPLATE/hardware_request.md) after review and software checks. A request is not a scheduled run.

This project has no support SLA and no claim of production flight readiness. Community help, code review and physical tests depend on maintainer availability. A missing response does not authorize a broader experiment.

Do not post credentials, signing material, private media, serial numbers, precise locations or restricted SDK reports. Do not paste private raw evidence into an external AI service by default. The maintainer can provide a minimal publication-approved summary or independently authored synthetic reproduction.

For suspected security problems involving sensitive information, use [private vulnerability reporting](https://github.com/bibek849/msdk-ios-lab/security/advisories/new), enabled for this repository. If the option becomes unavailable, open only a minimal issue requesting a private reporting route; include no exploit, secret or sensitive attachment. This support path does not imply that the experimental project has a security certification.
