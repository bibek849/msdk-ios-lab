# Claude Code contributor entry point

Read and follow [AGENTS.md](AGENTS.md), which is the authoritative shared contributor guidance.

Start with [the quickstart](docs/CONTRIBUTOR_QUICKSTART.md) and [contributor prompt](docs/templates/CONTRIBUTOR_AGENT_PROMPT.md). If the contributor connected the `msdk-ios-lab` MCP server, use `inbox_status`, `inbox_events` and explicit `inbox_ack`; receipt does not authorize coding or hardware. Recheck current GitHub assignment, scope and source revision before acting. Keep credentials outside prompts and the repository. Use only the contributor's own authorized account and budget.
